# SCT_WD_2 – Stopwatch Web Application

An interactive and user-friendly stopwatch web application developed as part of the SkillCraft Technology Web Development Internship.

## Task

Create an interactive stopwatch application that allows users to start, pause, and reset the stopwatch while tracking and displaying lap times.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record and display lap times
- Accurate time measurement
- User-friendly and responsive interface
